Paso 1 · Instalación

¿Dónde instalo Mercury?

🐧

Ubuntu / Debian

Paquetes oficiales con apt: se instala mercury-recommended.

🪟

Windows

Mercury tiene soporte para Windows 10 y 11. Una opción práctica: Ubuntu en WSL.

🧩

Código fuente

Para otras distribuciones: descargar el tarball y compilar con configure y make.

Descargas oficiales: dl.mercurylang.org

Paso 1 · Instalación

Instalar con apt (Ubuntu 24.04 / WSL)

# 1. Clave del repositorio oficial
$ sudo apt install wget ca-certificates
$ wget -O /tmp/paul.asc https://paul.bone.id.au/paul.asc
$ sudo cp /tmp/paul.asc /etc/apt/trusted.gpg.d/paulbone.asc

# 2. Agregar el repositorio de Mercury
$ echo "deb http://dl.mercurylang.org/deb/ noble main" | sudo tee /etc/apt/sources.list.d/mercury.list

# 3. Instalar y comprobar
$ sudo apt update && sudo apt install mercury-recommended
$ mmc --version

Para Debian 12 cambia noble por bookworm. En Ubuntu debe estar activo el repositorio universe.

Ojo en Windows

Dos programas llamados mmc

Microsoft Management Console

Windows ya trae un mmc. Si lo escribes en CMD o PowerShell, abre esa consola.

Melbourne Mercury Compiler

El nuestro. Instálalo en WSL, o pon la carpeta bin de Mercury antes que la de Windows en el PATH.

Paso 2 · El archivo

Un programa, un archivo .m

hola.m

Extensión

El código fuente de Mercury siempre termina en .m.

Nombre = módulo

Si el módulo se llama hola, el archivo debe llamarse hola.m.

Paso 3 · Primer programa

Hola, Mercury

% hola.m
:- module hola.
:- interface.
:- import_module io.

:- pred main(io::di, io::uo) is det.

:- implementation.

main(!IO) :-
    io.write_string("¡Hola, Mercury!\n", !IO).

▶ Pruébalo en glot.io

Paso 3 · Qué hace cada parte

Anatomía del programa

Avanza con ↓ y retrocede con ↑: se resalta una línea a la vez

:- module hola.:- interface.:- import_module io.:- pred main(io::di, io::uo) is det.:- implementation.main(!IO) :-    io.write_string("¡Hola, Mercury!\n", !IO).
Módulo. Su nombre debe coincidir con el del archivo: hola.m.
Interfaz. Lo que el módulo muestra hacia afuera. Cada declaración termina en punto.
Importación. Trae la biblioteca de entrada y salida, io.
Declaración de main. Recibe y devuelve el estado del mundo (di, uo); det: siempre da una solución.
Implementación. Aquí empieza la lógica del módulo.
Definición de main. El punto de entrada del programa. !IO representa el estado del mundo.
Imprime el texto y pasa el estado al siguiente paso.
Paso 4 · Compilar y ejecutar

Del .m al ejecutable

# Compilar (sin la extensión .m)
$ mmc --make hola

# Ejecutar
$ ./hola
¡Hola, Mercury!

En Windows nativo el ejecutable es hola.exe.
